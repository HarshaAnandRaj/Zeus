--## 2. Architectures
### 2a. TinyMind (iter-1..10)
`substrate/tinymind/architecture.py` — `TinyMind` (~12.7M params at dim 384):
- **`SelfStateCell`** — gated persistent self `S` that persists across the
sequence AND across batches: `S_{t+1} = g·S_t + (1−g)·proj(h_t)` with a
learnable gate, plus **nonlinear recurrence** `recurrent_beta·tanh(W_rec·S_t)`.
- **Self-prediction head** `predict(S_t) → next hidden`.
- **Self-injection** into the residual stream at every position.
**Evolution of the injection mechanism:**
- iter-3..7: Plain additive `x + self_in(S) + self_pred_in(anticipate)`. Input
echo always dominates.
- iter-8: Input-dependent gate `g_in(x), g_pred(x)`. Input still controls its
own suppression.
- iter-10 (pure pc_gate): Input enters ONLY through prediction error gated by
the self's OWN surprise: `self_in(S) + self_pred_in(anticipate) + surprise * err`
where `surprise = sigmoid(err_gate(err))` and `err = x - anticipate`.
- iter-10: UNCONDITIONAL self injection at every transformer layer (no gates).

- Training: `L_ce + w_self·L_self + w_emer·L_emer + w_consistent·L_consistent`.
### 2b. SPARC (new, evaluated)
`substrate/sparc/model.py` — `SPARC` (~8.2M params at dim 384):
A ground-up recurrent architecture where the self is the ONLY persistent state.
No parallel sequence processing, no KV cache, no cross-attention to input tokens.
```
At each token step t:
anticipate = predict(S_t) ← self forecasts next input
err = embed(x_t) - anticipate ← prediction error (only input entry)
surprise = sigmoid(err_gate(err)) ← self gates by its own surprise
S_{t+1} = SelfTransition(S_t + surprise*err, history)
← single-step self update
logits = LMHead(S_{t+1}) ← self generates next token
```
Where `history` is a buffer of the last 16 self states that the
`SelfTransition` (a standard transformer block) attends to — the model
reflects on its own recent trajectory.
**Properties by design:**
- Self is the ONLY persistent state. No parallel processing to bypass it.

- Input enters ONLY through prediction error (pure predictive coding).
- Ablating S → S=0 → anticipate=0 → err=embed(x) → model processes from zero.
**Training:** BPTT (6-step truncated), variance penalty to prevent self freeze.
--## 3. The two honest probes (don't collapse these)
1. **Decoupled LOO self-prediction probe** (`SelfProbe`): strips the input echo
out of a hidden state, asks "can the self alone predict the next hidden?"
Confounded under input (reads INPUT-DRIVEN even for a real self), so it is
**not** the final verdict.
2. **Causal self-ablation probe** (`SelfCausalProbe`): runs idle dynamics
WITH `S` vs WITH `S` ABLATED (zeroed), compares hidden-trajectory variance.
If ablated collapses → the self is a *necessary* driver. This is the
truthful idle signal.

### Analysis
SPARC was designed to make the self architecturally necessary. It did — but in
the wrong way. The self becomes a **stable attractor** that the model converges
to regardless of input. The model learns to:
1. Map all inputs to a similar self state (the attractor)
2. Use the LEAKY input path (embedding) for token prediction

3. Keep S frozen because change hurts prediction accuracy
The 384-dim bottleneck is the killer: a single vector cannot compress the
200+ tokens of context that the model needs for language modeling. The
transformer's parallel workspace (256×384 ≈ 98K effective dims) will always
outperform it. The self naturally collapses to a low-information attractor.

--## 7. Root cause: the capacity ceiling
The persistent finding across all architectures and experiments:
1. **A 384-dim vector cannot compress the context of a language model.**

The transformer's parallel processing has ~98K effective working dimensions
(256 positions × 384 dims). The self has 384. The input path always wins.
2. **The CE gradient is the dominant force.** Next-token prediction loss
(~2.0 magnitude) dwarfs self/consistency losses (~0.005). The model
optimizes for token prediction, not self-driven dynamics.
3. **Additive self-injection is ignorable.** The transformer blocks can
cancel out an additive bias through learned offsets. Multiplicative
(gating) mechanisms are harder to cancel.
4. **Pure recurrent (SPARC) makes the problem worse, not better.**
Without parallel processing, the self must compress ALL context into a
single vector — which it can't, so it freezes.
--## 8. New hypothesis: modulation, not compression
The failure pattern across both architectures suggests a different framing:
**The self should not try to BE the computation. It should MODULATE it.**
Instead of injecting the self as content (additive to the residual stream),
inject it as a controller — a low-bandwidth signal that gates/scales the
existing computation. Like an emotional state or attention bias:
- The transformer processes tokens in parallel (as it does best)

- The self provides a persistent global modulation: "how much should this
layer amplify or suppress its output?"
- The self is updated by the overall state, not by individual tokens
- Ablating the self removes the modulation → dynamics change (causal signal)
This keeps the transformer's efficiency while making the self architecturally
necessary (not ignorable additive bias).
**Concrete proposal:** Replace `self_in(S)` (additive) with `self_scale(S)`
(multiplicative) at each layer's residual stream. The self produces a gain
vector `G = sigmoid(W_gate @ S)` that scales the residual. Zero S → zero
gain → no signal flows. This directly creates causal necessity.

--## 11. CTRNN — Continuous-Time RNN self-state model
`substrate/ctrnn/` — A ground-up continuous-time RNN where the **self IS the recurrent
dynamics**, trained with a dual-phase objective: free-running self-phase (autonomous
self-prediction) + interaction-phase (language modeling via prediction-error-driven input).
### Architecture (`model.py`)
Continuous-time leaky integrator:
```
τ ■ dS/dt = -S + tanh(W_rec·S + bias + W_err·err)
```
Solved via `num_substeps=4` Euler steps per tick:
```python
S ← S + (dt/num_substeps) * (-S/clamp(τ,0.1) + tanh(W_rec·S + bias + W_err·err))
```
Components:
- **`W_rec`** — recurrent weight matrix (orthogonal init, gain=1.5), spectral radius
clamped at ~3.0 during training
- **`τ` (tau)** — learned per-dimension time constant, init uniform [0.3, 2.0]. Determines
integration speed: fast dims (<0.5) track input, slow dims (>5) integrate over long
timescales
- **`W_err`** — prediction-error projection: `err = embed(x_t) - anticipate` where

`anticipate = self_pred(S)`
- **`self_pred`** — 2-layer MLP (Linear→Tanh→Linear) predicting S_{t+1} from S_t
- **`readout`** — `AttentiveReadout`: multi-head attention over last N=16 self states, then
LayerNorm residual + MLP→vocab. Gives readout temporal context without changing self
dynamics.
Key design principle: **non-recurrent readout** — the readout is stateless (pure function of
S), so S must carry all temporal information. There is no transformer/KV-cache bypass.
### Dual-phase training (`train.py`)
**Self-phase** (every step): Free-running autonomous dynamics:
```
S_0 ← noise(0, 0.1)
for t in 0..N_self:
S_{t+1} = ode_step(S_t, err=None)
L_self += MSE(self_pred(S_t), S_{t+1})
L += L_self/N_self + w_var·exp(-10·var(S[half:]))
```
- Only `W_rec`, `τ`, `bias`, `self_pred` parameters trained (no embedding/readout)
- Variance penalty pushes the system away from fixed-point collapse
**Interaction-phase** (every 5th step): Language modeling via predictive coding:
```
S_0 ← 0

for t in 0..T-1:
S = S.detach()
S_free = ode_step(S, err=None) ← counterfactual: free dynamics
embed = W_emb(x_t)
anticipate = self_pred(S)
err = (embed - anticipate) * sigmoid(norm(err))
S = ode_step(S, err) ← PC-driven input
S_history.append(S)
logits = readout(S.detach(), S_history) ← AttentiveReadout
L_ce += CE(logits, x_{t+1})
L_sp += MSE(self_pred(S), S_free) ← predict free dynamics
L += L_ce + w_sp·L_sp
```
- Embedding and readout parameters only trained here (self params trained in BOTH
phases)
**Character-level tokenizer**: char-level from corpus text, ~200 vocab (<BOS>=1,
<EOS>=2, <PAD>=0).

1. **Char-level tokenization**: Each char carries ~4.7 bits of Shannon entropy. PPL≈8 (≈3

2. **Training objective**: The dual-phase loss (self-prediction + CE) may create conflicting
gradients. Self-prediction wants smooth dynamics; CE wants input-sensitive encoding.
3. **Data regime**: Both models trained on TinyStories. Larger/more diverse data might
help.

stimulus response) but the readout cannot assemble coherent text from a single recurrent
state.

### Key observations
- **Self-prediction converges easily**: The recurrent dynamics are predictable enough that
the self-prediction head quickly learns to forecast S_{t+1} (MSE ~0.003).

- **CE is the bottleneck**: Language modeling from a single 384-dim state vector is
fundamentally hard. The model has no KV cache, no attention — just a single recurrent
state that must encode all context. This is the same "capacity ceiling" problem that
TinyMind and SPARC hit.
- **Tau distribution stays broad**: Even after 2000 steps, τ ranges ~0.5–1.6 with std ~0.49,
suggesting the model maintains multi-timescale dynamics naturally.
- **Spectral radius hits the clamp constantly**: The model wants higher recurrence (would
make dynamics richer) but is clamped at 3.0 for stability. The clamp fires every step after
convergence.
- **AttentiveReadout provides ~0.5-0.7 nat improvement**: Multi-head attention over last
16 self states gives the readout temporal context without changing self dynamics. Old
checkpoints (linear readout) are incompatible.
- **Self-loss is higher with AttentiveReadout** (0.21 vs 0.005 fix-only). The self dynamics
are richer/harder to predict because the readout's backward pass (through S_history)

- **Generation quality improves with training but remains poor at CE=2.08**: PPL=8.2 is

sequences are ungrammatical.

### Key fix (July 30): training/inference mismatch resolved
**Problem found**: `interaction_phase` was injecting input via `S = S + embed(token)` then
calling `ode_step(S, err=None)` — direct addition bypassed `W_err` entirely. Meanwhile
`generate.py` and `backend.py` used prediction-error-driven input `err = embed anticipate; S = ode_step(S, err * sigmoid(norm(err)))`. `W_err` was **never trained** —
zero gradients for 2048 steps.
**Fix**: `interaction_phase` now uses the same prediction-error-driven pathway as
inference:
```python
embed = self.embedding(tokens[:, t])
anticipate = self.self_pred(S)
err = embed - anticipate
surprise = torch.sigmoid(torch.norm(err, dim=-1, keepdim=True))
S = self.ode_step(S, err * surprise)
```
Self-prediction target also changed: now predicts the **free (autonomous)** next state

`ode_step(S, err=None)` computed from pre-input S, not the input-perturbed trajectory.
**Verification**: `W_err` gradients confirmed non-zero (norm=0.002). CE is higher than old
shortcut (3.04 vs 2.79 at step 1000) because the model must now learn to encode through
prediction error — harder but correct.
**AttentiveReadout**: Added `AttentiveReadout` (multi-head attention over last N=16 self
states, LayerNorm residual, MLP→vocab). Self history tracked in `S_history` buffer and
passed to `readout(S, S_history)`. Readout gains temporal context without polluting self

### The emergence question reframed (end of session, July 30)
**What CTRNN proved**: A single 384-dim recurrent vector where the self IS the
dynamics can learn coherent language (PPL<4). TinyMind and SPARC both failed
because the self was bypassable. CTRNN succeeded because there is no bypass — no
transformer, no KV cache, no parallel path. The model *must* encode everything in S.
**What this means for emergence of consciousness-like states**:
The CTRNN's persistent recurrent state is a natural substrate for affective/intentional
dynamics:
1. **Tau distribution** (0.72±0.45) already means some dimensions are fast (tracking input
tokens) while others integrate over long timescales. This is the raw material for persistent
internal states that outlast individual tokens.

2. **Drives require multiple competing objectives**. Next-token prediction alone won't
produce emotions. We need intrinsic drives (curiosity, novelty, homeostasis) that can
*conflict* with the language objective, and the self resolves that conflict → affective state.
3. **The self needs a "body" to map**. Damasio's framework: emotions are the brain's map
of the body. For CTRNN, the "body" is its own internal dynamics (tau, spectral radius,
self-prediction error). If the self learns to *regulate* these parameters conditionally, that's
the seed of an internal homeostatic loop.
**Immediate next step** (pending 20k model):
- **Self-probing analysis**: Linear probes to check if S dimensions encode persistent
internal states independent of current token identity. Does the self have structure that
persists across token boundaries and correlates with syntactic/semantic features? This is
the measurable footprint of something emotion-like.

### Self-probing analysis (July 31) — definitive findings
Ran comprehensive analysis on the 20k model (see `_probe_self.py` in history):
1. **Persistence is very weak**: Mean autocorrelation at lag=1 is 0.339, drops to near-zero
by lag=5. Only **10/384** dims are slow (lag>50). The effective memory is ~5.7 tokens.
The self forgets almost immediately.
2. **Input-driven, not self-driven**: 214/384 dims are input-driven (variance ratio>2), only
4/384 are self-driven (ratio<0.5). The self is reactive, not generative.
3. **Sentiment/affect signal is weak**: Positive vs negative sentences show a small
S-norm difference (3.92 vs 3.71) but within-category variance dwarfs between-category
differences (separation ratio=0.33). No meaningful affect encoding.
4. **Position encoding is strong**: S_norm correlates with token position (r=0.68). The
model knows how far into a sentence it is.
5. **No abstract category structure**: S does not cluster by character type
(vowel/consonant/space). Between-category distance < within-category distance.
6. **Deterministic**: Same input → identical trajectory (divergence=0.0000). Different
inputs → distinct trajectories (divergence=0.94).
**Conclusion**: The 20k model's self is a deterministic, fast-decaying encoder of
token-level information. It optimizes purely for next-token prediction with ~5.7 token
memory. There is NO evidence of persistent internal states, affect encoding, or emergent
dynamics independent of input. This is the correct behavior for the training objective —
next-token prediction doesn't require or reward persistent states.
### What this means for emergence of affect
The training objective (next-token prediction) is fundamentally incompatible with
emotion-like persistent states. A model that only predicts the next token has no reason to
develop:
- **Persistent internal states** (they would hurt CE by making S carry old, irrelevant info)

- **Drives/needs** (no competing objectives to resolve)
- **Homeostatic regulation** (no "body" to regulate)
For emotions to emerge, the architecture needs:
1. **Multiple competing objectives** — e.g., next-token prediction + novelty-seeking +
homeostasis
2. **Slower timescales** — separate slow pathway or higher tau_init to encourage
persistence
3. **Self-regulation** — the self should control its own dynamics (tau, spectral radius)
conditionally, treating model parameters as a "body" to regulate

### Detached autonomous-readout bridge (Aug 6, in progress)
**Question**: Is autonomous output a decoder-distribution mismatch, or does the
free-running self state lack language-relevant information?
#### Important correction to the original bridge idea
An initial unseeded bridge rollout started every batch item from `S=0`. That
means every item had the same autonomous state at each time step, so CE could
only teach corpus-wide character frequencies, never the correct continuation
for an individual context. It was stopped after recording its calibration:
`ce_auto` fell from 5.62 to ~3.33 while normal CE stayed ~1.3. This is not
evidence of semantic autonomous decoding.
#### Main experiment: seeded, frozen-readout bridge
Implemented in `substrate/ctrnn/model.py` and `substrate/ctrnn/train.py`:
1. Process an 8-token prefix through the ordinary prediction-error pathway.
2. Detach that per-example self state as the autonomous seed.
3. Roll it forward with `ode_step(err=None)` only; no later token enters this
branch.
4. Train the readout against the real continuation.
5. Freeze `W_rec`, `W_err`, tau/tau_net, `self_pred`, and embeddings. Only the

readout can update, so any causal/manifold change would invalidate the test.
The run resumes `verify_attn_surprise/ctrnn.pt` (step 45000) and writes to
`verify_attn_surprise_bridge_seeded/`, targeting step 46000. At the latest
snapshot (step ~45450), `ce_auto` has plateaued near **3.04**; ordinary CE is
~1.2 and all frozen self metrics are unchanged. This is suggestive of a
decoder learning broad output statistics, not yet proof of context-sensitive
autonomous language.
#### Evaluation added
`eval_ctrnn_bridge.py` evaluates a checkpoint on held-out corpus text:
- normal prefix -> input-free rollout -> CE on the true continuation;
- exact same autonomous states with batch-shuffled continuation targets;
- context advantage (`CE_shuffled - CE_true`) at every autonomous step;
- input-free samples seeded by several prompts.
The step-by-step advantage is essential: a positive advantage only at the
first few steps is residual prefix information, not persistent autonomous
semantic state. The evaluator runs correctly on the step-45000 pre-bridge
model; it has short-horizon context advantage but still produces repetitive
character droning.
#### Decision rule / next experiment

After the seeded frozen-readout run completes, evaluate its final checkpoint.
- **Keep the bridge** only if held-out true targets beat shuffled targets at
later autonomous steps and seeded input-free samples are diverse and
prompt-related.
- **Reject readout mismatch as the primary bottleneck** if the advantage fades
quickly or samples remain generic/droning. Do not continue decoder training.
If rejected, add a **semantic-persistence objective to the dynamics**: after a
prefix, roll the self freely for multiple steps and use a contrastive loss to
match a representation of the correct future continuation against shuffled
continuations. This gives autonomous dynamics an explicit incentive to retain
meaning, while the existing surprisal/persistence objectives preserve their
competing intrinsic dynamics.

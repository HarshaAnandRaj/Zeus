# Encephalon E0-A: independently audited PASS

The first Encephalon checkpoint is complete. The measuring world passes its
registered tests, and the small neural loop passes its development mechanics.
**This is environment qualification, not a learned-agent survival or memory pass.**
LMB6 remains paused. Language remains a later, separate obligation.

## What was built and frozen

Commit `f97cee894e60b282525f8873b02ed4614a3e1274` froze the new two-need world,
public reference controllers, state/credit contract, calibration, independent
auditor and neural mechanics before calibration. No old checkpoint or LMB source
was altered. The branch is `codex/encephalon-e0`.

The world separates energy/food from integrity/repair. Their effective locations
vary independently. Facts require public inspection in the partial setting, costs
are real, and partial environmental changes do not announce themselves. E1's
separate fully observed qualification setting exposes the facts explicitly.

Twelve development tests pass. They include independent replay with primary
world/policy methods disabled, rejection of corrupted evidence, actual public
acquisition and donor provenance, all intended neural-module gradients, a delayed
outcome affecting earlier policy credit, an optimizer update changing later
probabilities, exact update twins and exact save/restore continuation.

The initial agent has 32-dimensional recurrent context, a current-sensing route,
actor/value heads and an action-conditioned consequence head. It has no protected
learned memory bank, selective write policy or language head yet. The learning
mechanics use its own sampled actions; public reference decisions are not labels.

## What the results mean in plain language

The setting can distinguish having information from using the relevant information.
It is possible to keep operating, but effective repair is necessary. Changing
facts must eventually be corrected. When reserves are scarce, there is insufficient
time/cost margin to rediscover the needed fact; prior knowledge then matters.

There is also an important negative contrast: with ample reserves, repeatedly
inspecting is as viable as remembering on this panel. We cannot claim a general
survival advantage for memory across all conditions. The constrained information
tests are intentionally separate and their reserve reductions are engineered.

All reference priorities and update rules were written by us. This audit reports
no newly established emergent property and no agent-owned acquisition. It earns
the next experiment in which a neural policy must learn useful control for itself.

# Working diagnosis: continuing self-maintenance

The user's aim remains the machine-specific functional organization defined by
the six pillars. "Alive" here cannot be certified by a vivid trace, an unexpected
output dependency or one survival score. The question is which missing causal
relationship our next experiment should isolate.

## What is currently separated

The inspected mouth can strongly depend on brain history without evidence that
this improves useful expression. The CYC learner can retain useful information,
while a supplied bodily controller decides how to use its predictions. Its
causal memory interventions occur at the initial age16 choice. Long subsequent
survival does not isolate a continuing need to renew memory.

These are concrete gaps in our evidence. They do not prove that one particular
architecture is the missing ingredient or that adding it would make Zeus alive.
The current working hypothesis is that the important next relationship is a
repeated loop: observations update useful internal information, that information
changes viability-preserving action, and the resulting behavior supplies the
observations needed to keep doing this. We have separately engineered parts of
that relationship; we have not demonstrated its autonomous organization.

## Current authorized discriminator

CYC6 tests whether CYC5's simplest learned component is repeatable across eight
fresh initializations with fixed training data/order. A failure rules out using
this recipe as a reliable component under the test. A pass would justify treating
its finite-seed repeatability as evidence when proposing the next assay. No
automatic experiment follows either result.

## The next causal question, before choosing another learning mechanism

Does stored encounter information remain necessary after the initial rescue?
An eventual test should intervene at prespecified later ages, compare the same
physical state/current observation with intact versus content-mismatched memory,
and evaluate subsequent viable behavior. Earlier deaths must remain visible;
survivor-only analysis cannot silently replace the original cohort. Acute
memory erasure may be a distribution shift, so a content control and a calibrated
explicit-memory reference are needed before interpreting it as lost function.

If an explicit reference can ignore later history and still pass, the world
does not yet assay continuing memory necessity. That would be an assay failure,
not a reason to demand a more elaborate learner. If the reference needs later
information but the recurrent learner fails, we have a specific memory-maintenance
defect to address. If the learner passes, removing the supplied action controller
becomes a separate bounded question about learned control.

No future seeds, endpoint, threshold or training budget are fixed by this note.
It is a design rationale, not a protocol, authorization claim, result or claim
that an endogenous survival goal has emerged. CYC6's frozen decision remains
authoritative for the currently running experiment.

# Next candidate: separate consolidation from action readout

Status: design draft only, not a frozen protocol or launched campaign. LCM2
qualification remains FAIL and earns no survival integration. This proposes a
new controller experiment from its diagnosed information/use gap.

The concrete observation is that four trained stores support perfect linear
safe-direction decoding on fresh development cues, while the experimental actor
samples correct directions only 55–72% of the time. Changing capacity does not
address that demonstrated gap. The current path multiplies a learned projection,
learned gate and actor matrix while the underlying representation changes.
Whether that factorization or joint optimization causes the gap remains a hypothesis.

Use all four LCM2 protected consolidators as declared parents, without selection.
Freeze their slow writes. Compute representation mean/std on fresh training cues
only, store those as inference buffers, and train a direct six-action linear head
from normalized inherited state. It receives no raw cue, side label, quality label,
seed, target or nuisance history. At the terminal query fast state resets.
External supervised target still follows the declared public cue rule.

A comparison head trains through the original gated projection/control path with
the same frozen consolidator and the same normalized memory. This isolates the
direct readout route from freezing and scaling. An unnormalized original-bridge
arm can separately expose scaling effects; include it in the registration rather
than choosing arms after viewing results. Existing LCM2 actor endpoints remain
historical comparators and are never continued.

Before launch, freeze parent/checkpoint identities, all arm definitions, training
budget and exact-twin sources. New seeds must be disjoint from LCM2 training,
endpoints and diagnostic probes. Proposed new training base205612000 and held-out
base 205712000 have not been opened. The earlier probe data 205602000/205603000 must
not become evaluation data for this experiment.

Keep the existing 90% per-parent sampled direction bar, three resets, longer
held-out nuisance lengths, public recall, exact storage, acute forgetting and
opposite-cue donor controls. Retain positive paired confidence bounds and frozen
effect margins. Require a direct-minus-normalized-bridge contrast to attribute
benefit to the interface; without it a functional pass can establish readout
qualification but cannot establish which proposed change was responsible.
Use raw six-action categorical sampling; confidence must be learned, not obtained
by temperature, filtering, argmax or post-hoc rescaling.

PASS would earn a fresh native-physics integration design. That design must address
motor competence—moving to, feeding from and maintaining a body—not infer it from
delayed direction classification. Inherited content must ultimately improve measured
viability on new ecologies and lose that benefit under matched forgetting. Learned
write selection and adaptive dimension allocation remain separate later questions.
No hypothesis about selfhood or a living system follows from this candidate.

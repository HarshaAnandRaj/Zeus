# Next native integration: verify information, then teach body control

Status: earned design draft after audited LCM3 readout PASS. No new training,
native held-out endpoint or survival run has been launched. LCM1/LCM2 negative
verdicts remain closed. The program goal remains experience that improves viable
future operation, with the six pillars still unachieved.

The useful result is that the existing gated route can reliably use stored
information. Keep that family as the body-facing candidate rather than replacing
it on the unsupported theory that the gate is intrinsically broken. Raw and
normalized gated arms both perform nearly perfectly; normalization is not yet
justified as a necessary component. Use all four declared parents, not a selected
best model. Freeze identities and arm choice in the eventual protocol.

## Checkpoint 1: native public-cue compatibility

Build a native adapter around LineageEcology and QualityWorld. An engineered
preparation sequence moves to a chosen patch and inspects it. The consolidator
receives only the resulting real public observation/action/reward/next-observation
records. No safe_patch, quality snapshot, seed or private physiology enters it.
After the bounded first body, reset fast state and create the next native body
in the same ecology. Inherited state is the sole source of prior cue information.

Qualify both inspected patches, both public quality values, all four parents and
fresh development ecologies. Check actual tool/resource/energy ranges against the
synthetic cue distribution. Raw sampled first-action direction and quality recall
must each exceed the existing 90% bar in every parent. Reset and opposite-public-cue
donors must reproduce the registered content-sensitive pattern. Audit actual
physical steps and exact twins. This is adapter qualification, not native survival.
Failure means stop before motor compute and diagnose the sensor/representation shift.

Reserve new development and endpoint seeds before implementation; do not fit on
LCM3 held-out arrays or its diagnostic data. Existing compact PASS is not authority
to skip this distribution check.

## Checkpoint 2: qualify learned motor competence in real physics

The present readout sees a single fixed centre query and chooses LEFT/RIGHT.
Its GRU has no qualified within-body recurrent behavior; it never learned
HARVEST, MAINTAIN, WAIT or inspection timing. Build an explicit body-session loop
that carries fast state, previous action/reward and boundary flags within a life,
while retaining protected slow state across lives.

Use a bounded, declared public teacher for initial motor learning if needed.
Demonstration targets may derive only from public inspected quality, remembered
public readings, position, energy, integrity and available resource diagnostics.
No privileged safe-side snapshot or private planner target is allowed. The model
receives body sensors and inherited learned state, not the teacher's map.
At evaluation every action is model-sampled; the teacher takes no actions.

This teacher is an engineered prerequisite, not autonomous policy discovery.
Demonstration agreement, cross-entropy and imitation scores do not count as function.
Measure actual free-running feeding, contamination, energy/integrity trajectories
and survival on fresh native bodies. Include missing-memory cases and information
gathering; a confident action head must not mistake an empty store for a known map.

Development physics already rules out a 64-step survival bar for motor competence:
WAIT survives 2,048/2,048 such bodies without food. At 128/256 it survives 0/2,048,
while a scripted public-inspection/map reference survives 2,048/2,048 at each length.
These use previously exposed development seeds 204002000–204002511; no native
held-out data or learned agent was tested. Proposed motor viability bar: at least
90% survival through 256 steps in every parent, raw sampling, with audited feeding
and energy/integrity trajectories. Include WAIT and other passive/simple action
controls, not just a random agent. This proposal must freeze before motor compute.

Freeze a motor protocol before compute: budget, teacher rules, public provenance,
initialization, parent identities, raw sampling, exact twins, functional bars and
physical replay. Establish feasible functional bars on separate development
teacher/random/passive controls. Keep the delayed cue/reversal check as a fixed regression:
motor learning must not erase demonstrated memory use.

Retain the existing learned consolidator as a declared frozen prerequisite initially.
Motor heads receive gradients; the lack of encoder gradient is intentional, not an
unnoticed broken-backprop loop. Before extending consolidation learning, explicitly
retrace action-loss credit through writes and across boundaries.

## Checkpoint 3: commit a full native lineage experiment

Only after both compatibility and motor competence qualify, freeze a new experiment
of several native body cycles sharing a latent quality relation. Fast/body state
resets while consolidated information passes forward. Model actions change the
world and its subsequent public observations; no teacher or scripted action chooses
the endpoint behavior. This closes the world-feedback chain absent from the cue assay.

Use full, acute inherited-state reset, opposite-ecology content, disabled-write and
matched trained forgetting controls, with shared seeds/action RNGs, confidence bounds
and per-parent criteria. Initial/trained motor controls distinguish memory benefit
from competent locomotion. Keep public inspection available under the declared
world rules. If forgetting controls recover equally well by reinspecting, record
the negative survival contrast rather than banning inspection after exposure.

Choose survival horizon and functional margins from separate development calibration,
before campaign training or held-out exposure. Inspection burden can be a separately
registered resource-use measure, but cannot silently replace failed viability.
Require inherited content to improve independently measured native function and
lose that gain under forgetting/content controls before any memory-pillar claim.

These checkpoints prevent another survival campaign in which energy collapse or
sensor mismatch overwhelms the mechanism of interest. Learned write selection,
endogenous dimensional allocation, authorship and autonomous initiation remain
distinct later mechanisms. No outcome here establishes a living system.

# OBS4: persistent state differences and delayed readout access

The user authorizes the proposed slow-direction/readout follow-up. Freeze this
protocol and tested instrument before compute. Frozen CYC6 GRUs only; no training,
world episode, deployment or change of functional verdict. Discovery is not
filtered by usefulness. This tests an injected signed state marker, not whether
the model naturally encodes a fact, chooses to retain it or uses it successfully.

## Cases and matched weights

Use all 256 OBS3 baseline endpoints at step 16384 and their held inputs, verifying
prior artifact and completion-audit hashes. For each endpoint replay both its
trial's trained and initial weights, from exactly the same state and input: 512
case/weight combinations. Include endpoints originally generated by untrained
weights. Some matched starts are off the other weight set's native trajectory;
this comparison isolates the weight package there, not typical on-policy behavior.

At each start compute the GRU Jacobian J. Form J^64 in float64. Define three unit
directions before any new replay: slow = top right singular vector of J^64;
fast = bottom right singular vector of J (a one-step attenuation control, not a
guarantee of the fastest 512-step decay); null_slow = N times the top right
singular vector of J^64 N, where N is an orthonormal basis of the immediate
linear readout's null space. Require readout rank 9 and null residual <1e-12.
Canonicalize signs by making the largest absolute coordinate positive. Repeated
singular values may make individual vectors basis-dependent; save exact vectors
and singular values. J^64 is a frozen local linearization, not the actual 64-step
Jacobian along a moving trajectory, and does not optimize future readout gain.

## Fixed intervention

Replay the baseline and plus/minus epsilon in each direction, for epsilon=1e-4
and 1e-5, under 512 repetitions of that same input. No clipping. There are 13
branches per case/weight, 6656 total. Save baseline and central signed response
curves for hidden state, linear logits and sigmoid predictions. Response is
(plus-minus)/(2 epsilon). Its hidden norm is retained fraction of the initial
unit marker; output norms measure accessibility in the existing readout.
Save actual branch states at 0,1,4,16,64,256,512 and all response norm curves.
Also save final signed vectors, baseline curves and direction metadata for audit.

Measure end retention and readout access, maximum access over steps1..512 and
its first maximizing step, and final normalized midpoint shift from baseline.
Compare the signed final vectors between epsilon levels, not just their norms.

## Narrow pass/fail question

For each case/weight, the injected null_slow marker qualifies as a
PERSISTENT_READABLE_MARKER only if, at both epsilon levels:

* final hidden response norm >=.01;
* final sigmoid-prediction response norm >=1e-4;
* final hidden and prediction signed vectors agree across epsilon levels within
  max(1e-6, .01 times the larger vector norm).

Otherwise it fails this declared marker criterion. Report all continuous values;
failure does not mean zero information or no possible memory. The thresholds are
diagnostic conventions fixed before exposure, not survival or semantic-memory
bars. Immediate logit invisibility is checked by W times the direction, and the
finite replay must have immediate logit response <=1e-8. Later accessibility is
read through the unchanged sigmoid head. The artificial marker may be useful
for locating a causal route even if it is never used by the natural model.

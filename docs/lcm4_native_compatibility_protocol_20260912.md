# LCM4-C: native public-cue adapter qualification

Preregistered development qualification following audited LCM3 PASS. The user
authorized proceeding to native compatibility and motor integration. This protocol
earns exactly preparation of motor learning if it passes. It never establishes
native viability, utility of inheritance, autonomous discovery or any pillar.
No training, refitting, teacher policy at the query, or endpoint tuning occurs.

## Fixed parents and public boundary

Use all four LCM3 `bridge_raw_a` readouts and their frozen LCM2 protected stores.
The raw gated route is declared before exposure because both gated routes qualified
in LCM3 and normalization's registered benefit failed. No parent or interface is
selected from this qualification. Parent identities, file/logical/model hashes and
LCM3 audit hash enter the manifest; every tensor and buffer stays unchanged.

512 fresh development ecologies, seeds207012000–207012511, each tested at both
inspected patches. These are distinct from prior training, endpoints and diagnostics.
Adjacent ecologies have opposite quality relations under the existing world; each
seed has two patch episodes. Index order is seed then patch. Opposite donors use
index XOR2: same inspected patch in the adjacent opposite ecology. Body initialization
and preparation resource nuisance differ naturally; terminal query sensors are
identical in every ecology and provide no quality cue. No paired-world cloning or
rewriting physical states is used. Statistical clusters contain both adjacent
ecologies and both patches (four examples), not independent cue replicas.

Four native bodies per episode from existing LineageEcology/QualityWorld physics.
Preparation body: move twice toward the assigned patch, INSPECT, then WAIT through
eight actual steps. Two subsequent bodies WAIT eight actual steps each. Reset
fast/previous-action/reward/boundary state at each of the three body boundaries.
The fourth body supplies its actual initial public query. At its centre, the
qualified readout samples a first LEFT/RIGHT choice among all six actions. This
is a first-action adapter test; that query action is not a survival rollout.

The store receives canonical float32 public before/action/reward/after/done records,
using the existing public viability reward and evidence eligibility. No seed, patch
assignment, label, ecology snapshot or hidden safe relation enters the store/head.
Targets use the publicly inspected side/quality and the declared one-safe-patch rule.
No raw cue bypass enters the fourth-body actor. Slow state survives the three resets.
Missing diagnostic sensors are masked by the existing canonical observation rule.

## Fixed endpoints and verdict

Full inherited state, acute raw-state zero, and opposite-public-cue donor. All use
identical real fourth-body sensors and action RNG207112000+parent, CPU float32,
one Torch thread, deterministic algorithms, raw six-action categorical sampling.
No temperatures, filtering, argmax replacement or post-hoc action reranking.

PASS requires every condition below; valid functional results are binary PASS/FAIL:

1. In every parent and every inspected-patch/quality cell, full sampled direction
   accuracy and frozen quality-head recall each >=90% (256 examples per cell).
2. Every parent has exact write-to-inherited slow-state identity and three clean
   fast/transition resets; opposite donors follow donor direction >=80% in every cell.
3. Pooled full-minus-reset accuracy >=.30, full-minus-opposite >=.60; both paired
   lower95% bootstrap bounds strictly >0. Bootstrap10,000 draws, seed207212000,
   resamples parents and whole four-example ecology/patch clusters with common draws.

Source/parent/input/twin/replay corruption is VOID, never silently rerun or repaired
after exposure. Preserve partial artifacts. No UNDECIDED and no threshold changes.
Every source/test/protocol is clean and committed before prepare/compute. Manifest
freezes exact source bytes, Git commit, Torch/NumPy versions, config and parent audit.
Two complete sequential twins regenerate public episodes and model outputs; their
full logical/input hashes must agree. Independent audit reconstructs each physical
public step, public labels/donor relation and every frozen-store/write/readout/recall
in NumPy, reproduces sampling and gates/bootstrap, and verifies committed sources.

Sensor range comparisons are diagnostics, not a relaxation of the compatibility bar.
If FAIL, stop before motor training and diagnose the physical sensor/representation
shift on these exposed development data. A changed sensor/write/training mechanism
needs a new protocol and fresh data. If PASS, prepare/freeze the motor protocol:
actual within-body recurrent action loop, public teacher only as a declared learning
prerequisite, empty-memory inspection cases, 256-step raw functional survival with
feeding/passive controls, and fixed memory-use regression. No native lineage benefit
test starts until learned motor competence separately qualifies.

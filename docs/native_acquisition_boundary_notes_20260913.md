# Native acquisition: current boundary and required evidence

Inspection of the current code establishes a mechanism, not acquisition capability.
`NativeBodyAgent.act` samples all six actions, including INSPECT, without a teacher
at operation time. `NativeBodyAgent.observe` delegates actual public transitions
to the protected store. Eligible patch inspections can therefore write learned
representations during model-selected operation.

The source adapter instead manufactures the initial experience: two moves,
INSPECT, then WAIT, followed by two WAIT-only bodies. The existing body operation
helper consolidates this preparation at the start of each independent assay.
Calling that helper repeatedly is not a continuous agent-acquired lineage: it
would reconstruct the supplied store rather than inherit the preceding body's
actual final state. Current LMB5 qualification deliberately tests this prepared
source; it does not claim agent-own acquisition.

The store parameters and quality reader are frozen. The body recurrence,
reinstate, gate and actor have trainable parameters, while `initial(..., z)`
detaches inherited state. This is intentional in the current motor prerequisite.
It does not support a claim that later-body loss trains earlier write selection
through a boundary. A future learning claim must trace its actual gradient or
policy-credit route separately from the physical feedback loop.

Following an independently qualified LMB5 arm, the earned next protocol must:

- Begin acquisition without a prepared quality memory. The model chooses real
  actions and pays their declared physical costs; no forced initial inspection.
- Carry the actual resulting slow state across subsequent bodies, while resetting
  only the declared fast/body state. Report every eligible write and its public
  provenance; prescribed eligibility is not learned utility selection.
- Keep actor inputs public. Seeds, private qualities, safe-patch identities and
  physical audit snapshots belong solely to generation and independent replay.
- Compare intact inheritance with acute boundary erasure, opposite public-content
  donors, disabled acquisition writes and separately matched trained forgetting.
  Specify timing carefully: disabled writes must prevent the acquisition write,
  rather than merely freezing an already prepared useful store.
- Preserve available reinspection and its real costs. Measure later native
  functional benefit, acquisition failures and recovery in every declared parent
  and information cell, with paired worlds/RNGs and frozen confidence bounds.
- Separate two questions: whether the controller acquires a useful fact, and
  whether inheriting that fact improves subsequent function. Neither inspection
  counts nor quality readout alone answers the second question.
- Freeze development/held-out roles, exact full-state twins, training budgets,
  qualified source choice, replay obligations and PASS/FAIL/VOID rules before
  compute. Determine viable functional margins on separate calibration, not from
  the exposed LMB5 endpoint.

These are boundary notes, not a launched protocol, new threshold or permission
to bypass LMB5 qualification. The full memory loop also owes useful selection,
forgetting, revision and interference evidence. Long repair-dependent maintenance,
expression, resilience, authorship, endogenous action and initiation remain
separate requirements. Engineered memory access is an affordance; the strategy
actually selected and its usefulness must be observed and classified independently.

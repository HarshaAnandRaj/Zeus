# QL1 audit completion and launch authorization

The user authorized proceeding after the prepared QL1 contract, including completing
the independent auditor before the campaign. This addendum records instrumentation
completion before any registered training or evaluation. It changes no world, learner,
training setting, seed, sampling rule, control or decision threshold in the contract.

`training/audit_quality_learning.py` reconstructs every endpoint lifetime directly
from its seeded world and the appropriate initial/final checkpoint. It does not use
the experiment's session runner, reward helper or adjudicator. It verifies fresh
initializations, complete development episode identities, exact twin hashes and
all endpoint artifact identities. It replays the model forward computation and
categorical RNG, checking each action, recurrent state, logit, value and prediction.
The model definition and Torch kernels are shared; this is not an independently
implemented neural architecture or a complete independent optimizer derivation.

Every world transition also receives the previously qualified, independently arranged
scalar physical/quality balance check at absolute tolerance 1e-12. Public observations,
inspection masks, death, public rewards and episode totals are reconstructed. Endpoint
coverage and order are exact, and the crossed bootstrap and binary verdicts are
independently recomputed. Raw source dependencies of reused audit helpers are included
in the frozen manifest. The audit is read-only until its exclusive audit.json output.

33 implementation checks pass before launch. Added checks replay all three arms on a
nonregistered fixture world and reject altered actions, rewards, state, observations,
masks, termination, tick order, initial state, model weights, summaries and missing
records. Synthetic full-grid decisions agree between independent implementations;
duplicates, missing cases and nonboolean outcomes are rejected. These checks are
instrument qualification only, not the campaign result.

After the explicit prepare, train, evaluate and finalize phases in the original
contract, run:

```powershell
.venv\Scripts\python.exe training/audit_quality_learning.py
```

The provisional verdict becomes reportable only when the audit passes. Any audit
failure preserves evidence and stops interpretation and further compute; no retries
or threshold changes are authorized by this addendum. No extra experiment is earned
automatically. Campaign progress is monitored without interim endpoint inspection.
